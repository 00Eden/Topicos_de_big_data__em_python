# 🎯 Objetivo

Este repositório tem como objetivo armazenar e organizar os códigos desenvolvidos ao longo da disciplina, abordando conceitos fundamentais de:

- 📈 Análise de Dados
- 🗄️ Manipulação de grandes volumes de dados
- 🧠 Lógica de programação aplicada ao Big Data
- 🐍 Programação em Python
- 📊 Bibliotecas para análise e visualização de dados
